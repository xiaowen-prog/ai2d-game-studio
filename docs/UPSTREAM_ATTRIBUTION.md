# 上游代码与归属说明

造境基于 [Innate-Labs/Noobi.ai](https://github.com/Innate-Labs/Noobi.ai) 二次开发，保留原始 Git 历史以便追溯，不把上游提交改写成个人原创历史。

## 本项目新增部分

- 「造境」产品名称、中文文案、视觉预览与本地在线桥接
- 2D 游戏制作流程、项目数据、历史恢复、导出和 Windows 适配相关的本轮改动
- `docs/product/` 下的个人项目需求、验收和交接记录

## 必须保留的边界

- 上游项目没有发布统一项目许可证；没有得到上游作者明确授权前，不为上游代码添加新的开源许可证或作排他性版权声明。
- `build/NOTICE.md` 保留上游项目、Codex CLI、Electron、React、Three.js、Godot 等依赖说明。
- 第三方依赖继续按各自包内许可证执行。

## 发布口径

本仓库可以作为「造境」个人衍生项目公开展示；公开展示不等于取得上游代码的重新许可权。若要把整个仓库作为可再分发的开源软件发布，需要补充上游作者对衍生与再许可范围的明确许可。
