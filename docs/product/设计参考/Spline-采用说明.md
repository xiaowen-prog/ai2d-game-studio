# Spline 制作台设计采用说明

**2026-11-06 用户确认 Spline 为主参考。本轮交付 3-0 独立设计预览，具体布局待确认；正式界面保持原样。**

来源：[Refero · Spline DESIGN.md](https://styles.refero.design/style/b36d5c7c-9b28-4c99-b5a8-69ce03621410)。已读取颜色、字体、组件、层级、布局与使用规则，并查看 Refero 收录的截图。这是网站视觉参考，不是 Spline 编辑器源码；本项目继续只做 2D。

## 统一采用

| 部分 | 采用值 |
| --- | --- |
| 底色 | 黑色 `#000000` |
| 面板 | 白色 8% 透明度；交互层白色 15% |
| 主按钮 | `#0062ff`，白字；同一区域一个彩色主操作 |
| 文字 | 白色、`#cccccc`、`#999999` |
| 圆角 | 卡片 24px，小面板 16px，按钮 12px |
| 排版 | 400/500 字重；4px 间距基础 |
| 装饰 | 色彩放在作品及少量图形上；面板不加大阴影 |

字体声明优先 Spline Sans / Inter，未下载字体，实际采用机器可用字体；中文使用系统中文字体。本轮没有新增字体服务或外网运行依赖。

## 从官网适配到制作台

- 统一的顶部进度替代原来宽侧栏；中间主要展示人物、场景与游戏画面，右侧为 AI 对话、确认和修改。
- 人物页以两张大图供选择，动作仍属于人物阶段；确认流程与已有产品一致。
- 官网的大标题和章节留白调整为可操作的工作台密度，桌面内容最大宽度 1664px。窄窗口将 AI 对话排到画面下方。
- 右上状态选择用于审阅首次使用、制作中与失败提示，正式产品不会保留该工具栏。
- AI 输入保留 Enter 发送、Shift + Enter 换行及中文选字保护。示例输入在切换页面、失败和等待状态时保留在当前预览内存中；不冒充真实项目保存。

## 素材与范围

人物、竹林沿用 Linear 预览内已复制的项目素材。没有图片生成、模型调用、游戏运行、登录或导出动作。预览只演示本地页面切换、确认、修改影响、版本影响和放大查看。

该 Spline 静态稿与 Linear 对照稿已按用户选择从工作树删除，仅保留历史说明。当前公开视觉以 `src/renderer/design/StudioPreview.tsx` 和 `studio-preview.css` 为唯一来源。
