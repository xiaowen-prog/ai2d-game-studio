# Linear 设计参考采用说明

**用户于 2026-11-06 选择 Linear，要求直接按 Refero 的 DESIGN.md 制作游戏制作台预览；只做 3-0，确认后再改正式界面。**

来源：[Refero · Linear DESIGN.md](https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1)。已读取页面 DESIGN.md 的 Tokens、Components、Do's and Don'ts、Surfaces、Layout 和 Quick Start。该页面是 Refero 对 Linear 网站样式的整理，不是 Linear 官方产品组件源码。

## 本次采用

| 项目 | 采用值 |
| --- | --- |
| 背景／层级 | `#08090a`、`#0f1011`、`#161718` |
| 边框 | `#23252a`、`#383b3f`；细边框区分层级 |
| 正文／次要文字 | `#d0d6e0`、`#8a8f98`；标题白色 |
| 主按钮 | `#e4f222`；同一个主要操作区只出现一个彩色主按钮 |
| 圆角 | 卡片 12px，按钮／输入框 6px，状态标签 4px 或胶囊 |
| 字体 | Inter Variable / Inter 优先，系统字体后备；中文使用系统中文字体，不打包商业字体 |
| 字重／间距 | 400、510、590；4px 基础节奏，常用 8／12／24／32px |
| 装饰 | 不给按钮、卡片、正文加装饰渐变，不用大阴影和大圆角 |

官网宣传页的超大标题、96px 章节间距改为制作台所需的 24–32px 标题与紧凑布局；保留已经确定的左侧创作步骤。交互流程取自本项目，颜色与组件尺寸取自参考规范。

## 预览素材与边界

- `linear-preview/index.html` 是单独的设计稿，可点击切换页面、示例状态和弹窗；不连接制作台接口，不存入项目，不调用模型。
- 两个角色和竹林图均复制自已有 2-4 保存素材。页面上的组合只是静态设计示意，不能当成新生成游戏或试玩结果。
- 未下载 Inter 字体文件；机器没有 Inter 时采用规范允许的系统后备字体。颜色、组件圆角与层级按上述值实现。
- 不修改 Noobi.ai 的正式页面、业务代码、用户存档、依赖或构建产物。

## 怎么看

打开 [独立预览](linear-preview/index.html)。默认看场景页；点击左侧查看人物、方向、试玩与交付布局，右上角切换首次使用、制作中和失败提示。

网页顶部的“3-0 设计预览”及状态切换是审阅设计用的辅助入口，正式产品不保留这条预览工具栏。
