# 2-8 俯视完整小局：由你验收

**看三件事：AI 能把旧试玩做成三波战斗、能按一句话改难度、人物与场景保持原样。**本轮已接入功能，尚未生成或试玩完整小局样例。

## 打开与制作

1. 双击项目根目录 `打开2-8俯视制作台.command`，再点俯视项目卡片。第一次会复制已有项目到独立续做区；之后继续读取这个副本，原 2-6 数据保留。打开本身不调用模型。
2. 当前保存的普通剑气草稿是“雪山剑气试炼”，碰墙即消失。如果显示“已停止”，从左侧历史记录选择“核心试玩草稿”，点击恢复并确认影响。恢复不调用 AI，也不会替你确认游戏。
3. 查看核心试玩，点击确认保存，再点击“制作完整小局”。如果你已有确认过的反弹版，则沿用该版的碰墙反弹规则；本轮不会自动加反弹。
4. 等 AI 完成，在“完整游戏”中点击游戏画面后操作。若提示未登录，在设置中登录现有 Codex 账户后重试；若生成失败，保留错误信息和项目，不把旧试玩当成新成果。
5. 先看下表，再试一句话修改。满意后点击“确认完整游戏并保存”；到此停止，不自动导出或进入下一节点。

制作和修改由你的点击触发，使用现有模型账户。训练敌人为两种简洁形状，人物和背景沿用已有图片；音效在本机合成，不新增图片或音乐 API 调用。

## 验收标准与指标

| 维度 | 怎么验 | 通过标准 |
| --- | --- | --- |
| AI 生成 | 从已确认核心试玩制作完整小局 | 输出能操作的真实游戏，有三波、升级与胜负；不是只有文字或视频；完成后等待确认 |
| 继承 | 对照原试玩 | 人物、发型、衣服、动作、背景、墙的位置及剑气碰墙规则保持 |
| 开始与操作 | 不开始先等 5 秒；再 Start / Enter，WASD 移动、J 攻击 | 开始前不刷怪、不扣血；开始后能移动与攻击，敌人向人物移动，有慢耐打/快脆弱两类 |
| 波次 | 逐波清敌，核对剩余数量 | 默认恰好 4、6、8 个；未刷出和存活敌人均计入剩余数，清零才推进；不会因等待自行通关 |
| 伤害 | 发射剑气击中敌人，再让敌人接触人物 | 实际命中才扣敌人生命；初始人物生命为 5；受击后至少 1 秒保护，不因重叠瞬间扣光 |
| 升级 | 清完第一、二波，分别用按钮或 1/2/3 选择 | 每次只能选一项：伤害 +1、速度增加初始值的 15%、恢复 2 生命且不超上限；选择前战斗暂停，选择后生效 |
| 胜负 | 清完第三波；另开一局让生命归零 | 分别显示胜利/失败；结算后停止刷怪、伤害与计时，显示击杀数、完成波次与用时 |
| 暂停 | Esc / Pause 后等 5 秒，恢复；切出窗口再回来 | 人物、敌人、剑气、受伤、刷怪与用时全部停住；恢复可继续；切出自动暂停；升级选择不能用 Esc 跳过 |
| 重来 | 游戏中、暂停、升级、胜利和失败时用 R / Play Again | 均回到第一波、满生命、初始速度和伤害、0 击杀和升级；旧敌人、剑气和延迟刷怪不残留 |
| 音效 | 攻击、命中、受伤、升级、结算；再静音/调音量/重来 | 对应事件有短音效，结算不连续重复；静音与音量有效，重来保留音量设置 |
| 一句话修改 | 输入“每波改成3、4、5个敌人，人物、场景和剑气规则保持不变” | AI 输出新版本；实际三波与说明都改为 3、4、5，其余指定内容不变；新版仍须确认 |
| 保存与恢复 | 确认新版本后关闭重开；从历史恢复修改前版本 | 新版保存完整；恢复后数量和确认状态随对应版本恢复；恢复本身不重新生成 |
| 节点边界 | 确认完整游戏 | 保留完整局，不自动启动导出或下一节点 |

建议按行记“通过 / 不通过 + 问题”。关键项出现无法生成、不能打完、修改无效、素材变样或旧版丢失时，不判本节点通过。上述是验收要求，尚非实测结果。
