# 2-5 核心试玩怎么验收

**这一节点让 AI 把已确认的人物和场景变成可玩的横版小样，再用一句话加入二段跳。**

已保存样例可从项目根目录的 `打开2-5核心试玩.command` 打开，点项目卡片后查看核心试玩。这个入口禁用生成，仅用于查看和试玩，不消耗模型额度。

| 操作 | 看到什么算通过 |
| --- | --- |
| 点游戏窗口，按 A/D | 人物左右移动，保留原人物和森林背景 |
| 按空格越过矮障碍 | 障碍会挡人，跳跃能够越过 |
| 接触金色收集物 | 物品消失，计数加一，原地停留不重复加分 |
| 未收集齐就碰目标 | 不显示完成 |
| 收集齐并到达右侧目标 | 显示 COMPLETE |
| 空中再按一次空格 | 二段跳确实再次向上，第三次不再跳；落地恢复 |
| 收集物品后或完成后按 R | 人物回到起点，计数清零，物品恢复，完成提示消失 |
| 历史中恢复“核心试玩草稿” | 恢复单跳；再恢复已确认版回到二段跳，不调用 AI |
| 关闭、重新打开 | 人物、背景、二段跳、确认状态一致 |
| 查看流程 | 停在核心试玩，没有开始完整游戏；俯视试玩仍未开放 |

真实 AI 生成及“加入落地恢复的二段跳，其他不变”已由验收脚本执行并独立记录；完整窗口通关尚未确认通过，由用户验收。查看样例不必再生成。实测结果、失败记录与范围以本目录验收报告为准。
