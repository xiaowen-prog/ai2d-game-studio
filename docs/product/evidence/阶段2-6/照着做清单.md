# 2-6 俯视核心试玩：由你验收

**本次看两件事：俯视小样能移动、攻击；AI 能把剑气改成只反弹一次。**

## 怎么打开

双击项目根目录 `打开2-6核心试玩.command`，浏览器打开已保存的普通版，点击游戏画面后操作。反弹样例制作已按你的要求停止；要亲自验证 AI 修改，双击 `打开2-6制作台.command`，点击项目卡片，输入“剑气碰墙反弹一次，其他保持不变”。制作台可以查看草稿、修改、确认和恢复历史。新生成/修改会使用现有订阅，单纯浏览与恢复不会调用模型。

## 通过标准与指标

| 验收项 | 操作 | 通过指标 |
| --- | --- | --- |
| 移动 | WASD 分别移动，再斜走 | 四方向可动；斜走不明显加速；遇墙不穿过 |
| 攻击 | 朝一个方向走一下，再按 J；攻击时短按另一方向，等动作结束再发射 | 剑气沿最近实际移动方向发射；攻击锁定期间按方向键不会偷偷转向；人物播放攻击动作 |
| 命中目标 | 瞄准三个练习目标发射 | 实际碰到才命中；每个只记 1 次，最多 3/3 |
| 原版剑气 | 在起点朝右墙发射 | 第一次碰墙消失，无反弹 |
| 修改版剑气 | 在起点朝右墙发射 | 第一次碰墙转向；第二次碰墙消失；最多 1 次反弹 |
| 保持无关内容 | 对比两个版本 | 人物、衣服、发型、背景、目标数量、地图和速度保持 |
| 重来 | 命中后、连续发射后按 R | 回起点；目标全恢复；计数 0/3；场上剑气清空 |
| AI 持续修改 | 恢复普通版本，输入“剑气碰墙反弹一次，其他保持不变” | 新版实际反弹，修改后等待你确认 |
| 保存与恢复 | 确认、切换历史、关闭重开 | 恢复对应版本与确认状态，未自动开始完整游戏 |

出现问题时反馈“哪一项、做了什么、实际发生了什么”即可。助手未代你自动试玩或确认通过，游戏效果以你的操作为准。
