# 3-1 正式界面：你来验收

**这一节点只验“制作台是否清楚、好用，原来的操作有没有保留”。AI 与游戏效果仍由你亲自检查。**

## 打开

1. 若旧制作台窗口还开着，先正常退出。
2. 双击项目根目录 `打开3-1正式制作台.command`。
3. 回车打开横版，输入 `2` 打开俯视；点击“继续最近的制作”里的项目卡片。
4. 右上角太阳/月亮按钮切换深浅色；本次主方案是深色。

打开不会自动调用 AI。普通网页预览地址仍是旧的 3-0 设计稿，正式功能应在此桌面入口验收。

## 验收标准与指标

| 维度 | 怎么做 | 通过标准 |
| --- | --- | --- |
| 页面清楚 | 打开已有项目 | 顶部能看见当前阶段；左边是已保存成果，右边能找到确认与修改；不显示预览稿的假项目数据 |
| 原功能完整 | 查看人物、动作、场景、试玩、完整游戏与交付的已到达阶段 | 对应成果可查看；未到达的阶段不能跳过；确认、重试、修改、恢复、导出入口按当前状态出现 |
| 输入习惯 | 输入一行，Shift+Enter；用中文输入法选字；普通 Enter 发送 | Shift+Enter 换行；选字不误发；发送一次只产生一个请求，不重复提交 |
| 草稿保留 | 在一个阶段输入但不发送，切到另一个阶段输入不同内容，再切回；退出重开 | 两个阶段各自的文字均保留，不串台；回到首次打开的阶段可继续编辑 |
| 人物选择 | 查看两个候选，选择一个，再改衣服 | 未选人物不能确认；选中态明确；修改作用于选中人物，另一候选保留，真实结果由你判断 |
| 确认与影响 | 提交对已确认内容的修改；先取消，再重新提交 | 修改前说明影响；取消不执行；确认后使用当前版本制作；旧版可恢复 |
| 等待与失败 | 由你发起一次制作；如失败，查看提示 | 制作中不能重复发送，有停止入口；旧成果保留；错误说清下一步，草稿不因提交失败消失 |
| 预览读取 | 如遇图片或预览读取失败，点击“重新读取预览” | 只重新读取已保存成果，不启动新生成；读不到时不能把错误版本确认通过 |
| 窄窗口 | 缩窄到桌面程序允许的最小宽度 | 对话移到成果下方；能滚动找到输入、确认和版本入口，按钮不被遮住 |
| 版本与交付 | 打开“已保存版本”；按需要恢复或导出 | 恢复前有影响提示；导出沿用确认版本，不自动调用 AI，旧交付包保留 |

**指标：实际检查项目全部通过；误触发生成、草稿丢失、错误确认、关键按钮不可达均为 0 次。**未遇到的失败场景填“未测”，不要当作通过。涉及真实生成的项由你决定何时执行，沿用现有订阅配置。

反馈可以直接写：`3-1 通过`；或 `哪一步 / 做了什么 / 实际看到什么`。未确认前不进入 3-2。
