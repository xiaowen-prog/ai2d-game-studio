# 2-7 横版完整小局：后续由你统一验收

**这一节点看三件事：AI 能把旧试玩做成完整一局、能按你说的改规则、原人物与玩法保持。**

## 打开方式

1. 双击项目根目录 `打开2-7横版制作台.command`。首次打开会准备现有横版试玩的独立副本，原 2-5 样例保留。
2. 点击横版项目卡片。已确认的核心试玩下方会出现“制作完整小局”；点击后才开始调用 AI。
3. AI 完成后，在“完整游戏”中点击画面操作。尚未由助手生成完整游戏样例，不要把原跑跳小样当成本节点的生成结果。
4. 用下表验收，满意后“确认完整游戏并保存”。确认不会开始导出。

## 验收标准与指标

| 看什么 | 怎么操作 | 通过标准 |
| --- | --- | --- |
| 进入下一步 | 打开旧横版试玩，点击“制作完整小局” | 直接继承现有试玩制作，人物/场景不要求重新生成；结束后等你确认 |
| 开始 | 暂不开始，观察 5 秒；再点击 Start 或按 Enter | 开始前角色与计时不动；开始后正常计时与操作 |
| 进度 | A/D 移动、空格跳跃，收集物品 | 计数每件只加 1 次；沿用原来的单跳或二段跳，落地恢复 |
| 获胜 | 收齐物品并在时间内到达终点 | 显示 YOU WIN；未收齐不能获胜；结算后玩法和计时停止 |
| 失败 | 开始后不收集，等待倒计时到 0 | 显示 TIME UP；不会再触发胜利，能重新开始 |
| 暂停 | Esc 或 Pause，等 5 秒，再 Resume | 人物、动画、计时和玩法停住；菜单可用；恢复时不会突然跳跃或自动跑 |
| 重来 | 分别在游戏中、暂停后、胜利后、失败后按 R 或 Play Again | 回到起点，时间恢复满值、计数为 0、物品全部出现；无旧结算残留 |
| 音效 | 跳跃、收集、结算；切换静音、音量，再重来 | 对应操作有短音效；静音有效，重来后设置保留；结算音效不连续重复 |
| AI 持续修改 | 输入“把倒计时改成120秒，人物、地图和跳跃规则保持不变” | 实际倒计时与说明均为 120 秒；其他内容保持；新版仍需你确认 |
| 历史与重开 | 确认版本，再恢复旧版；关掉制作台后重开 | 对应规则、图片和确认状态一致；恢复本身不发起新生成 |
| 类型边界 | 打开俯视项目和横版完整游戏 | 俯视仍停在核心试玩；横版完整游戏确认后不会自动进入导出 |

默认一局 90 秒，可用自然语言调整到 30–300 秒。生成和修改由你触发，会使用现有模型账户；本节点音效为本机合成，不调用图片/音乐 API。

助手只完成开发、类型检查与构建；真实生成、游戏操作、听音和恢复效果均由你后续验收，当前没有填写业务通过。
