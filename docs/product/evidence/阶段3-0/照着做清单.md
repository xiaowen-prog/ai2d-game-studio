# 3-0 Spline 设计确认清单

**这轮只看设计，不检查 AI 和游戏效果。正式制作台尚未换版。**

- [打开新版 Spline 预览](http://127.0.0.1:38431/)。本机服务仅提供独立设计目录。
- 原 Spline 与 Linear 静态稿已按用户选择删除；本清单保留历史验收记录。

| 维度 | 怎么看 | 通过标准 |
| --- | --- | --- |
| 风格与画面 | 默认打开场景页 | 整体有游戏创作感，画面是第一视觉重点；不再像办公任务列表 |
| 步骤与操作 | 点击顶部人物、场景、完整游戏；看确认与修改入口 | 清楚当前在哪一步、这版成果是什么、下一步点哪里 |
| AI 修改 | 输入一句修改，Enter 发送；Shift + Enter 换行 | 能看到修改影响，返回后内容保留；中文选字不应误发 |
| 第一次使用／失败 | 顶部“查看状态”切换相应项 | 知道登录后怎么开始；失败时看得见旧成果及重试入口 |
| 版本与显示 | 点击版本记录、放大画面；调整你自己的窗口大小 | 恢复影响说明易懂；主操作可找到，窄窗口可向下查看 AI 对话 |

所有状态、确认、聊天和文件列表都是设计示意，不会调用 AI、改动项目、生成文件或启动试玩。用已有图片组合的画面标有“静态设计示意”。刷新后示例状态重置，不代表真实产品的保存行为。

反馈“设计可以”或指出画面、字体、颜色、按钮位置的调整即可。确认这版制作台布局后，才进入正式界面改造。
