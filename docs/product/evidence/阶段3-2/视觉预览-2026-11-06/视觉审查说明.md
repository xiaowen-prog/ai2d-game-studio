## 采用的参考、Skill 与提示词

视觉方向参考 [VALORANT](https://playvalorant.com/) 的清晰排版、游戏画面与克制的强调色，以及 [Rive](https://rive.app/) 的工具界面层次。只采用布局、色彩、留白与轻量反馈，不复制品牌素材，不引入 WebGL、视频背景或动画库。

按用户要求从 GitHub 读取并应用以下前端指导，未安装其 CLI、hooks 或更改全局配置：

1. [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：文字必须帮助理解与操作；避免无意义的英文小标题、假元数据和装饰编号；保留有用途的视觉特点。
2. [Impeccable](https://github.com/pbakaus/impeccable)：使用 [Distill](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/reference/distill.md)、[Typeset](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/reference/typeset.md) 和 [Craft floor](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/reference/craft-floor.md) 的精简、字号层级、可读性指导。未运行其自动检测或外部代理。

本次应用提示词（结合项目约束整理）：

> 审查造境的首页、六步制作台、版本和导出面板。逐项判断文字是否帮助用户理解内容、状态或下一步操作；删除只有装饰作用的英文眉题、坐标、编号、重复说明和空泛口号。保留用户指定的品牌及 slogan。让游戏作品成为视觉主体，以版式、配色和轻量 CSS 交互建立层次；不要新增动画库或复杂视觉技术。正文、按钮保持清楚可读，次要标签不小于 12px；窄屏也不能靠缩小字体挤内容。桌面 AI 输入区保持在视口内，对话独立滚动。沿用现有代码与素材，只在独立预览中修改，不触发 AI、试玩、真实确认、项目保存恢复或导出。工程检查与用户审美验收分别记录。

## 用户怎么看

1. 打开首页，判断字体、配色、游戏画面与留白是否满意，是否还有无意义文案。
2. 点「制作台」，观察画面与右侧对话区的主次，输入区是否容易找到。
3. 点制作步骤，查看选中反馈、角色页和关卡页；这些是界面演示，不会执行游戏。
4. 点「历史版本」「导出」，看面板是否清楚。生成、修改、历史恢复、持久化及真实导出仍按原 3-2 清单由用户验收。
