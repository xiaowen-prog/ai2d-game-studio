## 逐项修正

| 用户反馈 | 当前实现 |
| --- | --- |
| 制作台被当作全局导航，默认进入第三步 | 顶栏仅保留大厅与项目；制作台须指定示例项目，无项目的旧链接转到项目列表；首次进入从方向草稿开始 |
| 未做过的步骤打勾，后续步骤随意进入 | 初始无完成勾；显式确认本步才解锁下一步；当前步骤显示文字标签；修改或切换旧版本重新锁定后续步骤 |
| 图标意义不明、成果入口重复 | 路线标注、放大查看均加文字；标注只读；移除对话中的重复成果卡 |
| 没有试玩入口 | 画布上方提供可见但禁用的试玩按钮，旁边说明示例未接游戏；不制造虚假运行状态 |
| 版本位于首屏下方、三个重复历史入口 | 画布下固定最近三个演示版本缩略图，全部历史只保留一个入口；删除工具栏历史按钮与调参图标 |
| 左右重复标题、建议与任务错位 | 左侧说明成果，右侧说明可修改内容；角色比例与位置建议对应当前画面 |
| 对话无闭环、下一步按钮过强 | 快捷建议立即应用有限的本地演示动作并新增可切换快照；自由文本明确回复未应用；发送为主要动作，确认本步为次要动作 |
| 手机导出按钮隐藏 | 导出说明留在项目栏，窄屏可见 |
| 手机步骤与版本被截断 | 六步改为三列两行；最近三个版本使用等分列，保留全部历史入口 |
| 手机看图与输入相隔很远 | 画布和对话共享首屏高度，对话内部滚动；聚焦输入时收起导航与次要控件，继续显示场景与输入框 |
| 缩放裁切后不能拖动 | 100%–200% 分档缩放，鼠标拖动/触摸滚动查看，提供适应画布；放大面板保持 16:9 |
| 历史只有同图滤镜 | 删除滤镜伪版本。初始仅 v01，支持的比例、位置、方向文字或界面叠层变化形成独立状态快照 |

不采用“假处理中”来冒充模型工作。本地演示立即完成的动作直接展示结果；需要真实 AI 的请求如“把场景改成沙漠”不改变画面、不新增版本，也不显示成功。

## 用户验收顺序与标准

1. 打开项目列表，进入「林间跃迁」：应停在「游戏方向」，没有完成勾；第二步以后不可点击。顶栏不再出现全局制作台。
2. 点一次「确认本步，继续」进入角色；再点一次进入场景：仅此前手动确认的两步打勾，第三步显示「当前」。这些确认只属于本页演示。
3. 在场景页无需滚动整页就能看见「试玩」、版本栏、输入框。试玩不可用的原因应直接可见。
4. 点「主角放大一点」「主角靠左一些」：画面确实改变，版本依次增加到 v02、v03；点 v01 应恢复初始构图，已有版本不删除。
5. 输入「把场景改成沙漠」并发送：应提示没有应用，画面及版本数不变。
6. 点放大画面到 150%，拖动画布：应能查看原先裁出的区域；点「适应画布」回到全图。路线标注只用于查看，不表示已编辑关卡。
7. 窄屏检查：六步名称完整，导出说明可见，三个版本不被裁切；输入时仍能看到场景。实际手机键盘效果请用户补验。
