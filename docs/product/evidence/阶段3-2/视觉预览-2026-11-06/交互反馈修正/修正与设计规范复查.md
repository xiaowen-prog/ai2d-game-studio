# 交互反馈修正与设计规范复查

2026-11-06。适用于 `?design=refined` 独立视觉预览；停在 3-2，产品验收仍由用户进行。

## 用户反馈与修复

| 反馈 | 原因 | 本次处理 |
| --- | --- | --- |
| 输入区两层红框 | 外层 focus-within 和文本框 focus-visible 同时高亮 | 首页和制作台统一为单层柔和外框，文本框内层无边框、无独立轮廓；保留外层聚焦反馈 |
| 打开制作台文字贴边 | 通用 `.zp button` 优先级高于组件样式，覆盖 padding | 降低基础重置规则优先级；桌面两侧 20px，窄屏 16px；改善悬停底色 |
| 我的项目只是滚动且出现突兀线框 | 原来使用首页锚点行为；导航沿用通用焦点轮廓 | 独立 `view=projects` 项目页、语义链接、pushState 与 popstate；支持刷新和浏览器返回。鼠标点击无外框，选中用底部强调线，键盘焦点另有浅色提示 |

项目页仍使用两个示例项目，不读取真实存档。首页保留「最近的项目」，「查看全部」进入项目页；「新建项目」回到首页并聚焦想法输入。

## 整体设计规范复查

范围：首页、项目页、制作台的方向/角色/场景/交付内容、历史与导出面板；按当前预览的纸白背景、深色工具栏和珊瑚红强调色检查。

| 检查项 | 结果及处理 |
| --- | --- |
| 组件样式隔离 | 修正按钮重置优先级；根视图统一 `zp-view-*`，避免项目页与首页项目区类名重名造成导航缩进 |
| 焦点、选中和禁用 | 鼠标焦点不留导航外框；键盘 Tab/Enter 可导航且提示可见；输入框禁用双重边框；空内容发送仍禁用 |
| 字号 | 实际渲染检查未发现低于 12px 的可见文字；窄屏说明按钮改为有可访问名称的图标，未通过缩小文字挤空间 |
| 文字对比度 | 加深步骤数字、版本号、工具栏分隔符；最终采集的纯色背景文字达到普通文字 4.5:1、大字 3:1 的检查阈值；图片上的文字结合截图检查，禁用状态不纳入数值结论。本项不等同完整 WCAG 认证 |
| 间距与操作目标 | 打开制作台按钮补内边距；弹窗标题去掉多余顶边距，关闭目标扩大至 40px；输入框统一内边距和 8px 圆角 |
| 页面与内容语义 | 独立项目页可刷新/返回；方向、角色、交付页隐藏无关场景缩放/标记和版本条；快捷建议随步骤匹配 |
| 布局与响应 | 1440×960、1024×768、760×620、390×844 的代表页面已检查；未发现页面横向溢出。1024×768 下输入框底部 669px，在视口内；窄屏上下排列 |
| 弹窗与动态 | 历史、导出面板桌面/窄屏显示正常；Escape 可关闭面板。源码保留 prefers-reduced-motion 下关闭动画/过渡，未引入动画依赖 |

以上是本次覆盖页面与状态的工程检查，不替代用户审美验收或真实工作流验收。完整游戏和核心试玩的预览区域共用静态场景展示，本次未启动游戏。
