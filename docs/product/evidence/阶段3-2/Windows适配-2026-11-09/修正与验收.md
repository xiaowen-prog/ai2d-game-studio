## 具体修改

1. 新增 `npm run package:win`，生成带产品图标和名称的 Windows x64 ZIP，使用明确文件白名单，排除 Mac/Linux 运行程序。Mac 打包命令保留原本的本机 Electron 来源。
2. 随包提供锁定的 Codex 0.148.0 Windows x64 原生程序，PE 架构与 npm lockfile SHA512 已核对；运行时使用正确的 ASAR 外路径，Windows 查找使用 EXE，不选不可直接 spawn 的 npm CMD 脚本，隐藏探测时的控制台窗口。
3. 原 ZIP 导出调用 `/usr/bin/zip` 和 `/usr/bin/unzip`，现使用正式依赖 fflate 0.8.3 流式写入并逐文件回读 SHA256；支持中文/空格路径、取消、独立目录和旧文件保护。输出增加 Windows `.cmd` 启动脚本；Mac `.command` 保留。
4. 修正 Windows `Path` / `AppData` 等变量大小写、分号分隔和引号路径；引擎设置说明补充选择 Windows Godot EXE，加入 Windows 应用标识。
5. 生成、修改和历史恢复仍是原实现，没有迁移数据格式。用户数据留在系统应用数据目录，默认工程目录不变；Mac 数据未复制或覆盖。
