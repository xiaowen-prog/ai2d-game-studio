# 3-2 验收：把制作台装进 Mac

本次交付是 Apple 芯片 Mac 测试安装包。助手完成工程检查；安装、生成、修改和试玩由你验收。

## 先打开

1. 正常退出之前的制作台窗口，避免打开后仍停在旧版。
2. 打开项目目录中的 `Noobi.ai/release/AI2D-Game-Studio-0.1.0-preview.3.2-arm64.dmg`。
3. 把 `AI 2D Game Studio` 拖到 `Applications`，然后在 Mac“应用程序”中打开它。
4. 测试版仅有本地临时签名，没有 Apple 开发者签名与公证。如果系统阻止打开，保留提示并反馈；不要自行关闭系统安全保护。

## 继续原来的项目

双击项目根目录的 `打开3-2测试版.command`，输入 `1` 继续横版，输入 `2` 继续俯视。它优先打开已安装版；没有安装时打开本地生成的应用。

选择 `3` 或直接从“应用程序”打开，会使用默认制作台的项目列表。旧验收项目保存在独立续做区，因此可能不出现在这个列表中，不表示数据丢失。

旧续做区第一次准备时会复制此前的样例；已有续做区则直接沿用。不会打包、自动导入或代填你的登录信息。缺少登录时按首页提示登录；缺少引擎时进入设置的“首次使用准备”，沿用原 Godot 或按页面指引安装。安装新机器时需另行准备 Godot 和导出模板。

## 看什么算通过

| 维度 | 你怎么做 | 通过指标 |
| --- | --- | --- |
| 安装启动 | 安装后从“应用程序”打开，再退出重开 | 两次都进入制作台，不白屏，不需要手动启动开发服务器 |
| 首次使用 | 看首页和设置中的账户、引擎状态 | 未准备好时能看到下一步；输入想法不会因打开设置或登录而丢失 |
| 原成果继承 | 用专用入口打开一个旧项目 | 人物、场景、当前步骤、已确认结果与之前一致；不自动再生成 |
| AI 生成和修改 | 你主动制作一个待做步骤，再提一条具体修改 | 有真实成果；修改实际生效；无关内容保留；不是只有一段文字方案 |
| 确认与恢复 | 确认本版，再从历史恢复一版 | 当前画面与对应版本一致，确认状态不张冠李戴 |
| 保存 | 写一段未发送的修改，退出后从同一入口重开 | 原成果、阶段和草稿仍在；不会重复提交任务 |
| 游戏交付 | 已确认完整游戏后导出，按包内说明打开 | 导出版本与已确认游戏一致，可以开始、结束和重来 |

你操作“生成”和“修改”才会使用你的模型账户额度。本轮助手没有替你运行这些操作。

## 反馈格式

告诉下一会话：**哪一步、做了什么、看到什么、期望什么**。有问题时保留截图和项目，不删除数据。全部满意后明确说“3-2 验收通过”；仍有问题就继续修 3-2，不自动往后开发。
