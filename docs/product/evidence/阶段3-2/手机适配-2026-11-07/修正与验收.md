| 实际问题 | 修正 |

| 320px 首页作品名称和“打开示例制作台”相互重叠 | 作品标题与入口分成上下两行；手机和较窄横屏都留出独立位置 |

| 放大面板的“放大/缩小”被挤成竖排 | 控制按钮保持单行，提示文字在中间换行；手机面板按内容确定高度 |

| 输入框失焦引发重新排布，吞掉紧接着的一次按钮点击 | 按下工作区按钮时保持输入布局，先处理点击；实际验证一次点击发送及一次点击放大均响应 |

## 用户验收顺序

1. 打开首页，手机宽度下向下看到作品：作品名与打开按钮不重叠；类型切换、创建项目、查看全部都能完整点击。
2. 打开示例制作台，按自己的需要逐步确认：六步名称、当前状态、导出说明完整可见。
3. 在场景页查看版本和输入框。较矮的手机窗口可以向下滚动，直到发送及确认按钮完整出现，不会被固定容器截掉。
4. 点输入框打字：场景仍可见。发送或放大入口只需点一次；这里仍是隔离演示，不执行真实生成。
5. 打开放大、历史和导出说明：文字正常换行，关闭按钮始终可用。请用自己的手机补验软键盘弹出和收起的实际表现。
