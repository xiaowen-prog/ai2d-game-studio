# 2-7 横版完整小局

**把已经能跑跳的横版试玩，接成有开始、有进度、有胜负、可暂停和重来的一小局。AI 继续负责生成与按描述修改。**

## 本轮范围

依据已确认《技术适配声明》第 7 节，只开发横版完整小局。复用当前人物、动作、背景、地图、收集物、终点和单跳/二段跳规则，不重新生图，不增加敌人、联机或多关卡。俯视保留核心试玩，完整俯视游戏与导出仍未开放。

默认沿原路线做一关限时收集挑战：90 秒内收齐原有物品并到达终点获胜；时间耗尽失败。开始前显示目标和操作；游戏中显示收集进度与剩余时间；暂停冻结移动、动画和计时；胜负后停止计时与玩法，允许重新开始。保留 A/D、空格、R，增加 Enter 开始、Esc 暂停/继续及鼠标按钮。音效使用 Noobi 已有的本地合成工具，覆盖跳跃、收集、胜利和失败，可静音和调音量，不调用音乐或生图 API。

## 用户流程

确认并保存横版核心试玩 → 点击“制作完整小局” → AI 制作 → 查看完整游戏 → 输入如“把倒计时改成 120 秒，其他保持不变” → AI 输出新版本 → 用户确认保存。已确认的旧试玩也能直接继续，不必重新生成；每次生成由用户点击触发。确认完整游戏后停止，不自动导出。

## 技术与复用

沿用 Electron/React、Codex 规划/制作/审查、Godot 4、版本快照、素材证明、任务停止与失败保留机制。新增完整横版任务说明和 `.noobi/platformer-round.json` 解析器，明确当前任务、确认试玩版本、规则、菜单/提示节点和音效路径。人物、背景、动作资源及原试玩清单按已确认快照校验；新增音效为本地 WAV，复用素材注册能力。

复用原项目的游戏工程导入、脚本检查、网页导出及生成过程的完整交付检查，不另造游戏引擎或一套试玩器。当前阶段只开放本地音效工具，不附加新图、音乐或 3D 工具；自动修复上限沿用本项目 0 次，失败保留旧版，用户决定是否重试。

开发节点与产品内确认分开：本次用户放行 2-6 只允许继续开发，不替用户确认某份具体游戏草稿。产品仍要求当前试玩已确认，才能制作完整小局。
