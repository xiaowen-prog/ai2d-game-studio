## 交付与实现

| 内容 | 实现 |
| --- | --- |
| 应用 | `AI 2D Game Studio.app`，版本 `0.1.0-preview.3.2`，arm64 |
| 安装入口 | DMG 内应用和 Applications 快捷方式；ZIP 作为备用 |
| 本地签名 | macOS ad-hoc 临时签名；没有 Apple 开发者身份认证或公证 |
| AI 运行程序 | 随包提供已锁定的 Codex 0.148.0 arm64 可执行程序；从 ASAR 外的原生目录运行；不打包登录凭据 |
| 引擎准备 | 复用原有 Godot 发现与设置，补齐中文安装/导出模板指引；Godot 和模板不嵌入本安装包 |
| 用户数据 | 普通打开沿用 `~/Library/Application Support/AI-2D-Studio`；旧验收项目用根目录 `打开3-2测试版.command` 继续 |
| 旧项目保护 | 复用既有横版/俯视续做区；首次准备只复制原样例，不覆盖已存在的数据；不复制账号 |
| 复现打包 | `npm run package:mac`：准备本地运行程序和图标、编译、electron-builder 生成应用、系统工具生成 DMG/ZIP、检查文件与签名 |

安装后打开制作台不需要用户手动启动开发服务器。AI 生成仍需用户登录；游戏制作和导出仍需 Godot 4 与匹配模板，其他工具由原环境检测提示。

官方 Godot 安装入口使用 [4.5.1 存档](https://godotengine.org/download/archive/4.5.1-stable/)。导出模板在编辑器菜单“管理导出模板”中安装，参考 [Godot 官方导出说明](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html)。

## 维护文件

- `package.json` / `package-lock.json`：测试版版本和打包命令；未升级依赖。
- `scripts/packaging/prepare.mjs`：校对本机架构、固定 Codex 版本和仅本地签名；用系统工具转换现有图标格式。
- `scripts/packaging/distribute.mjs`：`hdiutil` 生成并校验 DMG，`ditto` 生成 ZIP；先写临时文件，再移到交付目录。
- `scripts/packaging/check.mjs`：检查必需文件、Codex 架构、临时签名、私有目录排除和校验值。
- `scripts/packaging/prepare-saved-workspace.mjs`：读取或准备旧项目续做副本，不登录、不生成。
- `src/main/main.ts`、`src/renderer/index.html`：统一应用名称、标题和背景。
- `EnvironmentSettings.tsx` / `studio.css`：补首次引擎准备说明。
- `build/NOTICE.md`：记录上游与运行程序来源。
