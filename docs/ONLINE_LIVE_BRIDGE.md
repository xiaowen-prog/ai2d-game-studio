# 造境私有在线真实制作台

## 这次新增了什么

- 私有 Site 保留 refined 视觉入口，并新增「打开实时制作台」入口。
- `?live=1` 会加载现有正式 React 制作台，而不是设计预览。
- 真实生成、修改、历史恢复和导出继续调用现有 Electron 主进程、Codex App Server、Godot 与本机项目目录。
- 浏览器与本机之间通过 `127.0.0.1:47621` 桥接；桥接服务只接受当前私有 Site 的来源，不接收任意跨域请求。

## 使用

```sh
npm run online:bridge
```

保持终端运行，再打开私有 Site 并点击「打开实时制作台」。网页断开时，关闭桥接终端即可；本机数据不受影响。

## 边界

- 不把 Codex 登录态、模型凭据或本机项目上传到 Site。
- 这是“在线界面 + 本机真实执行”，不是把生成服务托管到云端。
- 真实生成、试玩、恢复和导出由产品经理人工验收；本轮工程检查只覆盖类型、构建、桥接跨域限制和现有代码接线。
