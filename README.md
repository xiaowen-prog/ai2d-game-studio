## 安装测试版

打开 `release/AI2D-Game-Studio-0.1.0-preview.3.2-arm64.dmg`，拖入 Applications。仅 Apple 芯片 Mac；应用采用本地临时签名，未经过 Apple 开发者签名和公证。Windows x64 使用 `release/windows/Zaojing-0.1.0-preview.3.2-win-x64.zip`，完整解压后打开 `造境.exe`，未签名。继续旧验收项目可双击父目录 `打开3-2测试版.command`，先正常退出旧窗口。普通启动使用默认数据目录，旧验收项目使用各自续做区。账户、Godot 与模板按设置指引准备，未附带私人项目或凭据。

本轮新增的是最省事的私有在线桥接：不新买云服务器、不把 Codex 凭据放到网页。网页只负责界面，真实生成、修改、历史恢复和导出仍由本机现有制作台完成。

### 启动私有在线真实制作台

1. 在本机保持项目目录下的终端窗口运行 `npm run online:bridge`。
2. 打开上面的私有在线制作台，点右上角「打开实时制作台」。
3. 看到正式制作台首页、项目列表和 Codex 运行状态后，再开始生成或修改。

桥接默认只监听 `127.0.0.1:47621`，只接受本项目私有 Site 的固定来源；关闭终端即断开在线实时制作，但本机项目数据仍保留。

重新打包从本目录运行 `npm run package:mac`：固定版本 Codex 原生依赖需已安装，本机系统工具生成 DMG/ZIP，结果和 SHA256 留在 release。不自动上传或调用模型。

## 本地开发启动

现有本机项目可双击父目录的 `打开3-1正式制作台.command`，选择横版或俯视并沿用原续做工作区。确认完整游戏后点击“导出工程与网页游戏”，完成后打开交付文件夹。包内网页启动脚本需要 Python 3，工程用 Godot 4 导入。导出不调用 AI，也不新增公网部署。详细步骤见 2-10 清单。

使用 Node.js 22 或以上版本及 npm。安装依赖后启动桌面开发环境：

```sh
npm ci
npm run dev
```

制作游戏沿用 Noobi.ai 的 Codex 登录、素材能力以及 Godot 4 和 Web 导出模板。通过应用中的设置配置。源码未包含任何账户或密钥。

只查看本机已有项目、不调用模型：

```sh
npm run build
env -u ELECTRON_RUN_AS_NODE NOOBI_DISABLE_GENERATION=1 node_modules/.bin/electron .
```

本机生成项目、登录状态、引擎安装包和依赖不上传。重新克隆后，旧样例不会自动出现在项目列表中；可通过上方在线页面查看已发布样例。
