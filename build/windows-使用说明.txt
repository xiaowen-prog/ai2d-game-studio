造境 · Windows 测试版
把脑海里的世界，做成能玩的游戏。

适用：Windows 10/11 64 位（Intel / AMD x64）。不是 Windows ARM 原生包。

1. 将整个 ZIP 解压到固定文件夹，例如“文档\造境”。不要在压缩包内直接运行。
2. 双击“造境.exe”。旁边的 DLL、resources、locales 等文件必须保留。
3. 首次在“Codex 账户”登录自己的账户；测试包内置 AI 运行程序，不含账户或项目。
4. 制作 Godot 游戏时，下载 Godot 4 标准版，解压到固定文件夹。在制作台“环境设置 → 选择程序”选择 Godot 的 .exe。
5. 打开 Godot，在“编辑器 → 管理导出模板”安装与该版本一致的模板，再回制作台刷新环境。

这份应用不需要你启动服务器或安装 Node.js。AI 制作仍需网络、可用的账户权限和相应额度。
它是未签名测试包。若系统拦截，请保留提示并反馈；不要关闭系统防护。

保存位置：
- 设置、历史与账户：%APPDATA%\AI-2D-Studio
- 默认游戏工程：用户文件夹\Noobi Games
换应用文件夹不会自动换数据；不要删除上述数据目录。
Mac 上的旧项目不会自动同步到 Windows；不要直接覆盖另一台电脑的数据目录。

导出后：完整解压 game-package.zip，双击“打开网页游戏.cmd”。
独立网页游戏启动脚本另需 Python 3.8 或以上（制作台本身不需要 Python）。
从 https://www.python.org/downloads/windows/ 安装时勾选 Add Python to PATH。

验收顺序：打开应用 → 配置账户与引擎 → 新建并生成 → 修改 → 确认与恢复 → 重开检查保存 → 导出并打开。
这是待用户验收的 3-2 测试版；工程检查不代表 Windows 实机或游戏效果已通过。
